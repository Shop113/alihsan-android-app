# تطبيق مدرسة الإحسان WebView

هذه الحزمة تحتوي على إضافة WordPress وقالب مشروع Android يعرض الموقع `https://alihsan.free.nf/?i=1` داخل WebView.

## محتويات الحزمة

| المسار | الوظيفة |
|---|---|
| `wordpress-plugin/` | إضافة WordPress لإدارة إعدادات التطبيق وتوفير إعدادات عامة عبر REST API |
| `android-webview/` | مشروع Android Studio قابل للبناء إلى APK أو AAB |

## تثبيت إضافة WordPress

من لوحة التحكم اختر **إضافات → أضف جديدًا → رفع إضافة**، ثم ارفع ملف `alihsan-webview-app.zip` وفعّله. ستظهر الإعدادات في **الإعدادات → تطبيق WebView**. الرابط الافتراضي مضبوط على موقع مدرسة الإحسان، ويمكن تعديله إلى رابط HTTPS آخر.

## بناء التطبيق

افتح مجلد `android-webview` بواسطة Android Studio، ثم انتظر مزامنة Gradle واختر **Build → Generate Signed Bundle / APK**. للنشر على Google Play اختر **Android App Bundle (AAB)**، وللاختبار المحلي اختر APK. يلزم إنشاء مفتاح توقيع خاص بك وعدم مشاركته.

التطبيق يسمح بالتنقل داخل نطاق `alihsan.free.nf`، ويفتح الروابط الخارجية في متصفح الجهاز. زر الرجوع يرجع إلى الصفحة السابقة داخل الموقع قبل إغلاق التطبيق.

## ملاحظة مهمة

إضافة WordPress وحدها لا تستطيع عادةً تجميع APK على الاستضافة، خصوصًا في الاستضافات المجانية؛ لذلك أُرفق معها مشروع Android مصدره جاهز للبناء. الموقع يعمل عبر HTTPS، وهو مناسب لـ WebView. يجب اختبار تسجيل الدخول والنماذج على جهاز Android حقيقي قبل النشر.
